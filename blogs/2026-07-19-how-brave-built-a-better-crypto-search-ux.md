Brave Search is a privacy-focused search engine that doesn’t profile users, and delivers results from its own, independent index of the Web. It’s used by millions of people worldwide, and is the default search for many of the Brave browser’s 120+ million users. To support its crypto-aware audience, Brave Search integrates CoinGecko’s API to display real-time cryptocurrency data directly in the search engine results page (SERP).
